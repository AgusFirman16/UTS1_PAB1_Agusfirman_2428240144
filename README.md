# wisata_candi

DetailScreen Wisata Candi (Flutter) dengan tampilan layar penuh.

- Android/iOS: mode immersive (status bar & navigation bar disembunyikan).
- Chrome: klik pertama masuk fullscreen otomatis, atau pakai tombol fullscreen
  di pojok kanan atas gambar. Tekan Esc untuk keluar.

Jalankan: `flutter pub get` lalu `flutter run -d chrome`.
